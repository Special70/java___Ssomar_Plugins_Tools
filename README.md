# Important Notes
- This project is to be compiled using Java 21
- The JavaFX dependencies are in the pom.xml file. There's no need to download unecessary stuff.
- If ever this build fails, in windows, check the environment variables.
- You really need to download JavaFX on every computer you use just in case you work in both in a laptop or computer.

# How to run this??
- Go to the maven option then javafx -> javafx:run
